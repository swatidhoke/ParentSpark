# ParentSpark

**Frontend:** Basic HTML & CSS  
**Backend:** FastAPI  
**Database:** SQLite

## Setup & Run (macOS)

```bash
git clone <repo-url>
cd ParentSpark

python3 -m venv venv
source venv/bin/activate

cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
